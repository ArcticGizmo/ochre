# Design: agent grid (M5 slice 6)

Agreed 2026-11-26, before the UI was changed (`docs/ux-conventions.md`, Process), with its three open choices as drawn: **Grid** is its own title-bar view holding one task per window (like Git), panes swap by dragging one's header onto another (clicking an empty region or a "Not in the grid" chip is the way in without dragging), and the keys are Alt+1–8 to focus a pane, Ctrl+Shift+Z to zoom, Esc to restore and Ctrl+. for the next pane needing you. Published as a private design canvas at https://claude.ai/artifact/EbEaZCrYVKL9YAEFfpbz3E; this folder is its local copy. Ochre's own colours, as in `docs/design/m5-inbox/`.

Artboards in `project/`: `Main.dc.html` (a task's four agents in a 2 × 2: one working, one needing you with its Allow/Deny card in the pane, one ready, and an outside session read-only; the toolbar with the task, the agents not in the grid as chips, the Layout menu and the keys), `States.dc.html` (the Layout menu open with the nine presets as thumbnails, an empty region offering the agents to put in it, and a dormant agent whose composer resumes it), `Zoomed.dc.html` (one pane filling the grid, Restore and Esc, the others as chips) and `Task.dc.html` (a **Grid** button beside a task's agents). They render only inside the canvas, which supplies `support.js`. Sample tasks, agents, commands and folders are made up.
